# CampusFix AI

A beginner-friendly Flask + SQLite hackathon prototype for campus complaint management.

## Features
- Submit a complaint with an optional photo
- Rule-based category and priority suggestions
- Complaint search and filters
- Complaint status, priority, assignment, and notes
- Basic possible-duplicate hints using text similarity and matching location
- Dashboard statistics and category chart
- SQLite storage and complaint activity history

## Requirements
- Python 3.10 or newer
- Internet connection only for loading Chart.js from its CDN and Google Fonts; core complaint management runs locally.

## Run on Windows
1. Extract the project ZIP.
2. Open the `campusfix-ai` folder in VS Code.
3. Open Terminal → New Terminal.
4. Create a virtual environment:

   ```powershell
   py -m venv .venv
   ```

5. Activate it:

   ```powershell
   .\.venv\Scripts\Activate.ps1
   ```

   If PowerShell blocks activation, use Command Prompt and run:

   ```bat
   .venv\Scripts\activate.bat
   ```

6. Install packages:

   ```powershell
   python -m pip install -r requirements.txt
   ```

7. Start the application:

   ```powershell
   python app.py
   ```

8. Open `http://127.0.0.1:5000` in your browser.

## First demo
1. Select **Report a Problem**.
2. Submit a sample complaint, for example:
   - Title: Fan not working in Room 204
   - Description: The ceiling fan has stopped working and the room is hot.
   - Location: Block A, Room 204
3. Open **Complaints** and click the new complaint.
4. Use the demo staff controls to assign it and change its status.
5. Submit a similar complaint at the same location to see duplicate hints.

## Important limitations
This is a local hackathon prototype, not a production deployment. It does not include real authentication or protected staff roles, so anyone with access to the local app can use the demo management controls. Do not use it with real confidential student data until authentication, authorization, CSRF protection, secure secret configuration, and deployment hardening are added. Category and priority suggestions are rule-based, not generated by an AI model. Qwen integration is not included yet.
